# Social Metatag Preview module for Drupal 10 and 11

Metatag interface for editing Open Graph (Facebook), Twitter Cards, and search
engine markup - including social sharing images.

## Requirements

- PHP 8.3+
- Drupal 10.3 or Drupal 11
- [Metatag](https://www.drupal.org/project/metatag) `^2.0`
- [Media Library Form Element](https://www.drupal.org/project/media_library_form_element) `^2.0 || ^3.0`
- [jQuery UI Dialog](https://www.drupal.org/project/jquery_ui_dialog) `^2.0`
